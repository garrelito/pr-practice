# PR Practice

A tiny sandbox repo for practicing the GitHub pull request workflow with Claude Code.

## What is this?

This repo exists so you can learn how a real GitHub contribution works:

1. Make a change on a branch
2. Commit it
3. Open a pull request
4. Review and merge it

## Goal

The goal of this repo is to give you a safe place to expriment with pull requests
before doing it on a real project.
